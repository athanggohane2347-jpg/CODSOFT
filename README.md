## 🎮 Task 1 - Number Guessing Game

An interactive console-based game where players attempt to guess a randomly generated number with multiple difficulty levels and score tracking.

### ✨ Key Features

* Difficulty Levels (Easy / Medium / Hard)
* Random Number Generation
* Smart Hint System
* Score Tracking
* Best Score Tracking
* Multiple Rounds
* Input Validation
* Interactive Console Interface

## 📊 Task 2 - Student Grade Calculator

A student performance evaluation application that calculates total marks, percentage, grades, and generates a professional report card.

### ✨ Key Features

* Student Name Validation
* Multiple Subject Support
* Total Marks Calculation
* Percentage Calculation
* Grade Assignment
* Performance Remarks
* Professional Report Generation
* Input Validation

## 🏧 Task 3 - ATM Interface

A banking simulation application that allows users to perform ATM operations through a secure menu-driven interface.

### ✨ Key Features

* Balance Inquiry
* Deposit Money
* Withdraw Money
* Transaction Counter
* Banking Workflow Simulation
* Input Validation
* User-Friendly Interface
